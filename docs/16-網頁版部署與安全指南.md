# 網頁版部署與安全指南

> 網頁完整版的架構、啟動方式、區網安全模型與疑難排解。研究背景見 [14-網頁版瀏覽器能力研究](14-網頁版瀏覽器能力研究.md)，決策紀錄見 `.scratch/mac-linux-web/issues/03~05`。

## 架構：同一份底層

```
瀏覽器 ── HTTP(/api/*) + WebSocket(/ws) ── server.js ──┐
                                                       ├─ pty-core.js（共用核心）
Electron 主進程 ── ipcMain IPC ── electron/main.js ───┘
```

- `pty-core.js`（repo 根目錄）：pty 生命週期、asciinema v2 錄製、agent 控制介面、錄像管理、chokidar 檔案監聽，全部只寫一份。桌面與網頁各接一層薄薄的傳輸：
  - 桌面：`emit(channel, payload)` → `win.webContents.send`（`pty:data` 冒號通道名，preload 既有契約不變）。
  - 網頁：同一個 `emit` → WS 廣播 `{type:'pty-data', ...}`（連字號幀名，spec 05 決策）。
- 前端零改動原則：`app.js` 只在頂部加一段 Web Shim IIFE——偵測到桌面版（`window.fanboxEnv.isDesktopApp`）直接返回；瀏覽器裡把 `fanboxPty / fanboxFs / fanboxAgentCtl` 對映到 WS 幀、`fanboxRec` 對映到 `/api/web/rec/*`，其餘程式碼原樣跑。

## 啟動

```bash
npm install          # ws@8.21.3 + chokidar 是僅有的兩個新 runtime 依賴
node server.js       # 本機模式：綁 127.0.0.1，免密碼（現狀不變）
FANBOX_LAN=1 node server.js   # 區網模式：綁 0.0.0.0，強制密碼
```

| 環境變數 | 說明 |
|---|---|
| `FANBOX_PORT` | 主服務埠（預設 4567；預覽源固定 +1） |
| `FANBOX_LAN=1` | 開區網模式（繫結所有網卡 + 強制密碼） |
| `FANBOX_HOST` | 自訂繫結位址（如 `192.168.50.23`），優先於 LAN 判定 |
| `FANBOX_NO_RECORD=1` | 關閉終端黑匣子錄製 |
| `FANBOX_AGENT_TOKEN` | 固定 agent 控制介面門票（預設每次啟動隨機） |

## 區網安全模型（spec 04）

- **分層密碼**：loopback 免密；LAN 模式下非本機請求必須持有效會話。首次以 LAN 模式啟動時自動生成 12 位隨機密碼，原子寫入 `~/.fanbox/webpass`（0600）。側欄「网页版」卡可顯示/修改。
- **會話**：`fanbox_session` cookie，HttpOnly + SameSite=Lax，30 天滑動過期，登出即失效；落盤 `~/.fanbox/websessions.json`，重啟不掉線。
- **CSRF**：SameSite + Origin 校驗（沿用 `originAllowed`，POST 與 WS upgrade 都驗）+ Host 白名單（本機網卡 IP 集 + localhost，任意域名仍拒——DNS rebinding 防護保留）。
- **暴力破解**：單 IP 連錯 5 次鎖 5 分鐘，失敗留痕 `~/.fanbox/webauth.log`。
- **傳輸**：v1 明文 HTTP + 密碼（自家區網嗅探風險的務實取捨）；HTTPS 化列為未來項。
- **靜態資源開放、API 全部把關**：未認證裝置能拿到外殼頁面，任何資料介面都吃 401；前端 shim 偵測後蓋全螢幕登入層。

## WebSocket 幀協議（spec 05）

單一 `/ws` 連線承載 pty 流 + fs 事件 + agent 控制：

| 方向 | type | 載荷 |
|---|---|---|
| 客戶端 → | `spawn` `input` `resize` `kill` `cwd` `proc` `watch-set` `watch` | 與 preload 同參；帶 `seq` 的請求回 `{type:'result', seq, r}` |
| 客戶端 → | `term-created` | agent 開窗回執 `{reqId, ok, id, error}` |
| 伺服器 → | `pty-data` `pty-exit` `fs-changed` `agent-touch` `agent-term-create` | 推送 |

- 會話歸 server 所有：瀏覽器重新整理/斷線不殺 pty；**無任何連線超過 30 分鐘自動回收全部終端**（長跑 agent 請保持頁面開著）。
- `input/resize/kill` 為發後即忘（與桌面 `ipcMain.on` 語義一致）；`spawn/cwd/proc/watch-*` 帶 `seq` 等回執。

## 網頁版功能邊界（spec 03）

完整：真實終端、檔案瀏覽/搜尋/預覽/編輯（含 Milkdown/Monaco 寫寫盤）、檔案監聽跟隨、終端錄影與回放匯出、agent 控制介面（`/api/agent/*` 由核心注入）、定時任務開窗。

降級：剪貼板圖片/檔案複製、截圖直通車（手動拖圖替代）、系統通知（非安全上下文改頁內 toast）。

不做：防休眠電源守衛、微信 ClawBot（手機開網頁版即是遠控路徑）、訪達 reveal。

## 疑難排解

- **手機打不開**：確認 `FANBOX_LAN=1` 且防火牆放行 4567；Host 白名單只收本機網卡 IP，用 IP 訪問而非 mDNS 域名。
- **密碼忘了**：`cat ~/.fanbox/webpass`；側欄卡也能看。
- **終端自己關了**：觸發了 30 分鐘回收（期間無瀏覽器連線）；或 `node-pty` 未編譯（跑 `npm run rebuild`，降級提示會寫在終端面板裡）。
- **檔案改了沒亮卡**：確認目錄在監聽集（瀏覽過該目錄或有終端開在其下）；`node_modules/.git/.cache/.local` 等重目錄刻意不監聽（事件洪水治理）。
- **錄像在哪**：本機模式 `~/.fanbox/records/`，桌面版在使用者資料目錄 `recordings/`；保留最近 60 個 / 800MB。
